# Работа с Heimdall

В списке **доступных нод** найдите доступный сервер по имени, hostname или IP. Карточка показывает UNIX-логин, адрес SSH, разрешённые способы входа и роль. Кнопка копирует команду подключения. Разверните список ролей в карточке, чтобы посмотреть sudoers.

Нажмите своё имя внизу меню, чтобы открыть **Профиль**: факторы входа, SSH-ключи, UNIX-параметры и назначения. Вход в Heimdall и вход на сервер — разные настройки. Пароль веб-интерфейса никогда не копируется на ноды.

Для доступа к серверу должны одновременно выполняться условия:

1. Администратор включил синхронизацию вашей UNIX-учётки.
2. Есть назначение UNIX-роли на нужную группу нод.
3. Роль явно разрешает SSH-ключи и/или парольный вход.
4. Пользователь активен, обязательные факторы зарегистрированы, метки допуска разрешают доступ.
5. Агент подтвердил применение изменений. До этого карточка показывает ожидание синхронизации.

Если ноды не отображаются, администратор может проверить ваш профиль и назначения. Права администратора Heimdall сами по себе не дают UNIX-доступа.
